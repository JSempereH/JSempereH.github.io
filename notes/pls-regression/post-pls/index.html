What is Partial Least Squares Regression?

2026-05-22 Math

Notation

  • The $n$ observations described by $k$ response variables are stored in an $n \times k$ matrix $Y$.
  • The values of $p$ predictors collected on these $n$ observations are stored in an $n \times p$ matrix $X$.

We want to predict $Y$ from $X$. If $X$ has full column rank, this can be accomplished with ordinary multiple regression. But when $p \gg n$, $X$ is rank-deficient and we suffer from multicollinearity: $X^\top X$ is singular and the OLS estimator $\hat{\beta} = (X^\top X)^{-1} X^\top Y$ does not exist.

Two classical remedies are Principal Components Regression (PCR) and Partial Least Squares (PLS). Both replace the original $p$ predictors with a small number $M \ll p$ of linear combinations $z_1, \dots, z_M$, and then run OLS on those components.

Principal Components Regression

We apply the (thin) SVD to the column-centered $X$:

$$ X = U \Sigma V^\top, \qquad U^\top U = V^\top V = I_r $$

The columns of $V \in \mathbb{R}^{p \times r}$ are the loadings (directions in predictor space), and the columns of $Z = U\Sigma = XV \in \mathbb{R}^{n \times r}$ are the principal components (scores). PCR keeps the first $M$ components (those with the largest singular values) and fits

$$ \hat{Y}_{\text{PCR}} = Z_M \hat{B}_M, \qquad \hat{B}_M = (Z_M^\top Z_M)^{-1} Z_M^\top Y. $$

Because the columns of $Z_M$ are orthogonal, this reduces to $M$ independent univariate regressions.

The catch. PCA selects directions that explain the variance of $X$, completely ignoring $Y$. There is no guarantee that the directions explaining the most variance in $X$ are the most useful for predicting $Y$.

Python example

import numpy as np
from sklearn.decomposition import PCA
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

# Simulate data: 50 observations, 200 predictors, 1 response
rng = np.random.default_rng(42)
n, p = 50, 200
X = rng.standard_normal((n, p))
true_beta = rng.standard_normal(p)
y = X @ true_beta + rng.standard_normal(n)

# PCR: standardise --> PCA (keep M=10 components) --> OLS
pcr = Pipeline([
    ("scaler", StandardScaler()),
    ("pca",    PCA(n_components=10)),
    ("ols",    LinearRegression()),
])
pcr.fit(X, y)
print("PCR R2:", pcr.score(X, y))

Partial Least Squares

Reference: Abdi, H. (2010). Partial least squares regression and projection on latent structure regression (PLS Regression). WIREs Computational Statistics, 2(1), 97–106. https://doi.org/10.1002/wics.51

PLS improves on PCR by finding components that simultaneously decompose $X$ and $Y$, subject to the constraint that they explain as much as possible of the covariance between $X$ and $Y$. Because $Y$ participates in the construction of the components, PLS is a supervised dimensionality-reduction method, whereas PCR is unsupervised.

The NIPALS algorithm (univariate $y$)

Like PCR, PLS is not scale-invariant, so we first standardise each $x_j$ to mean $0$ and variance $1$. Set $\hat{y}^{(0)} = \bar{y}\,\mathbf{1}$ and $x_j^{(0)} = x_j$ for $j = 1, \dots, p$.

For $m = 1, 2, \dots, M$:

  1. Score: $z_m = \displaystyle\sum_{j=1}^{p} \psi_{mj}\, x_j^{(m-1)}$, where the weights are the inner products $\psi_{mj} = \langle x_j^{(m-1)},\, y \rangle$.

  2. Regress $y$ on $z_m$:

    $$ \hat{\theta}_m = \frac{\langle z_m, y \rangle}{\langle z_m, z_m \rangle} $$

  3. Update the fitted values:

    $$ \hat{y}^{(m)} = \hat{y}^{(m-1)} + \hat{\theta}_m z_m $$

  4. Deflate: orthogonalise each $x_j^{(m-1)}$ with respect to $z_m$:

    $$ x_j^{(m)} = x_j^{(m-1)} - \frac{\langle z_m,\, x_j^{(m-1)} \rangle}{\langle z_m, z_m \rangle}\, z_m, \qquad j = 1, \dots, p. $$

The output is the sequence of fitted vectors $\bigl\{\hat{y}^{(m)}\bigr\}_{m=1}^{M}$. Because each $z_m$ is a linear combination of the (deflated) $x_j$’s, we have $\hat{y}^{(m)} = X\hat{\beta}^{(m)}$ for some coefficient vector $\hat{\beta}^{(m)}$ that can be recovered from the PLS transformations.

Intuition. The weight $\psi_{mj} = \langle x_j^{(m-1)}, y \rangle$ is simply the (sample) covariance between predictor $j$ and the response. Predictors that correlate more strongly with $y$ receive larger weights, so $z_m$ points in the direction of maximum covariance with $y$, not maximum variance of $X$ alone.

Python example (using scikit-learn)

from sklearn.cross_decomposition import PLSRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import cross_val_score
import numpy as np

rng = np.random.default_rng(42)
n, p = 100, 50
X = rng.standard_normal((n, p))
y = X[:, :3].sum(axis=1) + 0.5 * rng.standard_normal(n)

# PLS with M=5 latent components
pls_pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("pls",    PLSRegression(n_components=5)),
])

# 5-fold CV to choose M
for M in [1, 2, 3, 5, 10]:
    pls_pipe.set_params(pls__n_components=M)
    scores = cross_val_score(pls_pipe, X, y, cv=5, scoring="r2")
    print(f"M={M:2d}  CV R2 = {scores.mean():.4f} ± {scores.std():.4f}")

Penalised Regression: Ridge and Lasso

PCR and PLS tackle multicollinearity by projecting $X$ onto a lower-dimensional subspace. A completely different strategy is to keep all $p$ predictors but add a penalty term to the OLS objective that discourages large coefficients. Ridge and Lasso are the two canonical members of this family.

Ridge Regression ($\ell_2$ penalty)

Ridge solves:

$$ \hat{\beta}^{\text{ridge}} = \arg\min_{\beta} \left\{ \|y - X\beta\|^2 + \lambda \|\beta\|_2^2 \right\} $$

The penalty $\lambda \|\beta\|_2^2 = \lambda \sum_j \beta_j^2$ shrinks all coefficients continuously towards zero as $\lambda$ grows. The closed-form solution is

$$ \hat{\beta}^{\text{ridge}} = (X^\top X + \lambda I)^{-1} X^\top y, $$

which is always well-defined because adding $\lambda I$ makes $X^\top X + \lambda I$ positive definite even when $X^\top X$ is singular. Ridge therefore solves the collinearity problem directly, without discarding any predictor.

Key property. Ridge shrinks all coefficients but never sets any of them exactly to zero. It is best suited when you believe most predictors are relevant but their individual effects are small.

Lasso Regression ($\ell_1$ penalty)

Lasso (Least Absolute Shrinkage and Selection Operator) replaces the squared penalty with an absolute-value penalty:

$$ \hat{\beta}^{\text{lasso}} = \arg\min_{\beta} \left\{ \|y - X\beta\|^2 + \lambda \|\beta\|_1 \right\} $$

where $\|\beta\|_1 = \sum_j |\beta_j|$. There is no closed form; the problem is a convex quadratic program solved efficiently by coordinate descent.

Key property. The $\ell_1$ penalty has corners at zero, which causes the solution to be sparse: for large enough $\lambda$, many coefficients are driven to exactly zero. Lasso therefore performs automatic variable selection, it simultaneously shrinks and selects predictors.

Geometric intuition

The difference between Ridge and Lasso is most clearly seen in their constrained forms. Both minimise the RSS subject to a budget on $\|\beta\|$:

  • Ridge: $\|\beta\|_2^2 \leq t$ — the feasible set is a sphere (smooth, no corners).
  • Lasso: $\|\beta\|_1 \leq t$ — the feasible set is a diamond (corners on the axes).

The OLS contours are most likely to touch the diamond at a corner, where one or more $\beta_j = 0$, which is why Lasso produces sparse solutions while Ridge does not.

Python example

import numpy as np
from sklearn.linear_model import Ridge, Lasso, RidgeCV, LassoCV
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline

rng = np.random.default_rng(42)
n, p = 100, 150
X = rng.standard_normal((n, p))
# Only the first 5 predictors truly matter
true_beta = np.zeros(p)
true_beta[:5] = [3, -2, 1.5, -1, 2]
y = X @ true_beta + rng.standard_normal(n)

scaler = StandardScaler()
X_s = scaler.fit_transform(X)

# Ridge: cross-validate over a grid of lambda
ridge_cv = RidgeCV(alphas=np.logspace(-3, 3, 100), cv=5)
ridge_cv.fit(X_s, y)
print(f"Ridge  best λ={ridge_cv.alpha_:.4f}  "
      f"non-zero coefs: {np.sum(ridge_cv.coef_ != 0)}")  # always 50

# !! NOTE:
# Lasso: efficiently computes solutions for all lambdas at once (regularization
# path via LARS), then uses CV to pick the best stopping point
lasso_cv = LassoCV(cv=5, random_state=0)
lasso_cv.fit(X_s, y)
n_nonzero = np.sum(lasso_cv.coef_ != 0)
print(f"Lasso  best λ={lasso_cv.alpha_:.4f}  "
      f"non-zero coefs: {n_nonzero}")   # ideally close to 5

Running this you will typically see Ridge keeping all coefficients non-zero while Lasso zeroes out most of them, correctly identifying the sparse structure.

Elastic Net: Ridge + Lasso

When predictors are strongly correlated, Lasso tends to pick one arbitrarily and discard the rest. Elastic Net combines both penalties:

$$ \hat{\beta}^{\text{EN}} = \arg\min_{\beta} \left\{ \|y - X\beta\|^2 + \lambda_1 \|\beta\|_1 + \lambda_2 \|\beta\|_2^2 \right\} $$

It inherits sparsity from Lasso and the grouping effect from Ridge. In practice it is often the safest default among penalised methods.

from sklearn.linear_model import ElasticNetCV

enet_cv = ElasticNetCV(cv=5, random_state=0)
enet_cv.fit(X_s, y)
n_nonzero = np.sum(enet_cv.coef_ != 0)
print(f"ElasticNet  best λ={enet_cv.alpha_:.4f}  l1_ratio={enet_cv.l1_ratio_:.2f}  "
      f"non-zero coefs: {n_nonzero}")

ElasticNet  best λ=0.1445  l1_ratio=0.50  non-zero coefs: 51

When to use each method

Scenario Recommended method
$p \gg n$, dense signal (many weak predictors) Ridge
$p \gg n$, sparse signal (few true predictors) Lasso or Elastic Net
Correlated predictors, sparse signal Elastic Net
Interpretability via latent structure matters PLS
Unsupervised compression of $X$ then regression PCR
